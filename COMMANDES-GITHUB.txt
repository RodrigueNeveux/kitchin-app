📋 ÉTAPE 1 : CRÉER LE REPO SUR GITHUB.COM
─────────────────────────────────────────────────────────────
1. Allez sur : https://github.com
2. Cliquez sur le bouton "+" (en haut à droite)
3. Cliquez sur "New repository"
4. Nom du repo : Kitchin
5. Description : Application de gestion de cuisine Kitch'In
6. Choisissez Public ou Private
7. NE COCHEZ PAS "Add README" (déjà créé)
8. Cliquez "Create repository"

📋 ÉTAPE 2 : COPIER-COLLER CES COMMANDES DANS LE TERMINAL
─────────────────────────────────────────────────────────────
(Ouvrez PowerShell ou CMD dans le dossier Kitchin)

cd Kitchin
git init
git add .
git commit -m "Initial commit - Application Kitch'In"
git remote add origin https://github.com/RodrigueNeveux/Kitchin.git
git branch -M main
git push -u origin main

📋 SI GITHUB DEMANDE UN MOT DE PASSE
─────────────────────────────────────────────────────────────
Option 1 : Personal Access Token (Recommandé)
1. Allez sur : https://github.com/settings/tokens
2. "Generate new token" > "Generate new token (classic)"
3. Donnez un nom : Kitchin-Local
4. Cochez la case "repo"
5. Cliquez "Generate token"
6. COPIEZ le token (vous ne le reverrez plus !)
7. Utilisez ce token comme mot de passe

Option 2 : GitHub CLI
winget install GitHub.cli
gh auth login

📋 APRÈS LE DÉPLOIEMENT
─────────────────────────────────────────────────────────────
Votre code sera visible sur :
https://github.com/RodrigueNeveux/Kitchin

Puis déployez sur Vercel en 2 clics :
1. Allez sur vercel.com
2. Importez votre repo GitHub
3. Cliquez Deploy !
