# Installation de Firebase

Firebase est déjà dans package.json mais n'est pas installé dans node_modules.

## Solution rapide

Exécutez cette commande dans le terminal (dans le dossier Kitchin) :

```bash
npm install
```

Ou si vous êtes dans le dossier parent :

```bash
cd Kitchin
npm install
```

## Alternative : Installation manuelle

1. Ouvrez un terminal dans le dossier `Kitchin`
2. Exécutez : `npm install firebase`
3. Attendez que l'installation se termine
4. Relancez le build : `npm run build`

## Vérification

Après l'installation, vérifiez que Firebase est installé :

```bash
npm list firebase
```

Vous devriez voir quelque chose comme :
```
firebase@10.13.0
```
