📋 ERREUR : "Could not resolve host: github.com"
─────────────────────────────────────────────────────────────
Cela signifie que votre ordinateur ne peut pas se connecter à GitHub.

📋 SOLUTIONS À ESSAYER (dans l'ordre) :
─────────────────────────────────────────────────────────────

SOLUTION 1 : Vérifier votre connexion Internet
─────────────────────────────────────────────────────────────
1. Ouvrez un navigateur
2. Essayez d'aller sur github.com
3. Si ça ne fonctionne pas → Problème de connexion Internet

SOLUTION 2 : Vérifier avec ping
─────────────────────────────────────────────────────────────
Dans PowerShell, testez :
   ping github.com

Si ça fonctionne → Passez à la solution 3
Si ça ne fonctionne pas → Problème réseau/DNS

SOLUTION 3 : Vider le cache DNS
─────────────────────────────────────────────────────────────
Dans PowerShell (en tant qu'administrateur) :
   ipconfig /flushdns

Puis réessayez :
   git push -u origin main

SOLUTION 4 : Utiliser GitHub Desktop (plus simple)
─────────────────────────────────────────────────────────────
1. Téléchargez GitHub Desktop : https://desktop.github.com
2. Installez-le
3. Connectez-vous avec votre compte GitHub
4. Ajoutez le repository local
5. Cliquez "Push origin"

SOLUTION 5 : Vérifier le proxy/firewall
─────────────────────────────────────────────────────────────
Si vous êtes dans un réseau d'entreprise :
- Vérifiez avec votre administrateur réseau
- Il faut peut-être configurer un proxy

SOLUTION 6 : Utiliser SSH au lieu de HTTPS
─────────────────────────────────────────────────────────────
1. Générez une clé SSH :
   ssh-keygen -t ed25519 -C "votre@email.com"

2. Ajoutez la clé à GitHub :
   - Allez sur : https://github.com/settings/keys
   - Cliquez "New SSH key"
   - Collez le contenu de : C:\Users\Admin\.ssh\id_ed25519.pub

3. Changez le remote :
   git remote set-url origin git@github.com:RodrigueNeveux/Kitchin.git

4. Poussez :
   git push -u origin main

╔══════════════════════════════════════════════════════════════╗
║        SOLUTION RAPIDE (à essayer en premier)                ║
╚══════════════════════════════════════════════════════════════╝

1. Vérifiez Internet :
   ping github.com

2. Si ping fonctionne, réessayez :
   git push -u origin main

3. Si ça ne fonctionne toujours pas, utilisez GitHub Desktop :
   https://desktop.github.com
